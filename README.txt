POKEMON: DISTORTION RIFT — fan game (free, not affiliated with Nintendo/Game Freak)

WHAT THIS IS
A complete GBA-style monster-taming RPG. 531 species (full Kanto/Johto/Hoenn dex
1-386 + all legendaries/mythicals Gen 1-9), real Infinite-Fusion-style fusing
(fuse any two Pokemon; 952 handmade community sprites included), 8 anime allies
(Goku, Luffy, Gojo, Naruto, Ichigo, Deku, Tanjiro, Saitama) as story characters
and starters with evolutions + custom signature moves, an epic Team Umbra vs
Giratina/Arceus storyline, and an AI twist (NEXUS companion, adaptive rival ECHO,
anomaly events, battle autopilot).

HOW TO PLAY
- Fastest: unzip, then open index.html in Chrome/Safari. Works, saves in the browser.
- iPhone: host it free (see below), open the link in Safari, then Share > Add to
  Home Screen for a fullscreen app-like icon. Touch controls (D-pad + A/B) appear
  automatically. Saves live in the browser.

FREE HOSTING (pick one, ~5 minutes)
1. itch.io — made for games. New project > upload this zip > "This file will be
   played in the browser" > set index.html as the entry. You get a public link.
2. GitHub Pages — push this folder to a repo named <you>.github.io; the game is
   live at https://<you>.github.io within minutes.
3. Netlify Drop — drag this folder onto app.netlify.com/drop (no account needed);
   you get a public link instantly.

SAVES
Progress saves automatically in the browser (localStorage) on whatever site you
host it on. Same browser + same site = your save is there when you come back.
